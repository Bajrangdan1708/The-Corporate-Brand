# Prodesk IT Landing Page

> A modern, professional, production-ready responsive landing page for **Prodesk IT** — a Digital Marketing & IT Services company.

---

## Project Overview

This project is a fully responsive, single-page landing website built for Prodesk IT. It showcases the company's services, values, and contact information with a premium, modern design aesthetic. The page is built entirely with vanilla HTML5, CSS3, and JavaScript — no CSS frameworks or external JS libraries are used.

The website features a glassmorphism sticky navbar, dark/light mode toggle, smooth scroll navigation, scroll-reveal animations, interactive service cards, a contact form with client-side validation, and a fully responsive layout tested across all common device widths.

---

## Features

- ✅ **Responsive Design** — Fully responsive from 320px to 1440px+
- ✅ **Sticky Navbar** — Glassmorphism/frosted-glass effect with `backdrop-filter`
- ✅ **Mobile Hamburger Menu** — Slide-in navigation with smooth open/close
- ✅ **Dark/Light Mode** — Toggle with `localStorage` persistence
- ✅ **Hero Section** — High-conversion layout with CTAs and decorative backgrounds
- ✅ **About Section** — Company overview with animated statistics
- ✅ **Services Section** — 3-card grid with hover lift and shadow effects
- ✅ **Why Choose Us Section** — 4 feature items with icons
- ✅ **CTA Section** — Gradient banner with action button
- ✅ **Contact Form** — Client-side validation with success message
- ✅ **Contact Information** — Email, phone, and location
- ✅ **Footer** — Navigation, social icons, and copyright
- ✅ **Hover Animations** — Button effects, card lifts, link underlines
- ✅ **Scroll-Reveal Animations** — IntersectionObserver-based section reveals
- ✅ **Accessibility** — Semantic HTML, ARIA attributes, focus states, keyboard navigation
- ✅ **Reduced Motion Support** — Respects `prefers-reduced-motion`
- ✅ **Performance Optimized** — Lightweight, minimal dependencies, semantic HTML

## Local Setup

### Option 1: Direct Browser

1. Clone or download this repository
2. Open `index.html` in any modern web browser

### Option 2: VS Code Live Server

1. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code
2. Right-click on `index.html`
3. Select **"Open with Live Server"**

### Option 3: Simple HTTP Server

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

## Deployment

This project is a static website and can be deployed easily on any static hosting platform.

### Vercel

1. Push this repository to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import the GitHub repository
4. Vercel will auto-detect it as a static site and deploy

### Netlify

1. Push this repository to GitHub
2. Go to [netlify.com](https://www.netlify.com)
3. Click **"Add new site" → "Import an existing project"**
4. Select the GitHub repository and deploy
